# Sales Performance Analysis Dashboard using Excel

## Project Overview
This project focuses on analyzing Global Superstore sales data using Microsoft Excel. The objective is to understand sales performance across different regions, product categories, years, and customer segments through data analysis and an interactive dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Conditional Formatting
- Data Cleaning Techniques

## Project Workflow

### 1. Data Cleaning
- Checked for duplicate records.
- Checked for missing values.
- Verified date and numerical data types.
- Checked data consistency.

### 2. Descriptive Statistics
Calculated the following metrics for Sales:
- Mean
- Median
- Mode
- Variance
- Standard Deviation
- Minimum
- Maximum

### 3. Sales Analysis
Performed sales analysis using Pivot Tables:
- Region-wise Sales Analysis
- Category-wise Sales Analysis
- Yearly Sales Trends
- Segment-wise Sales Analysis

### 4. Data Visualization
Created visualizations to understand sales performance:
- Category-wise Sales Bar Chart
- Yearly Sales Trends Line Chart
- Segment-wise Sales Bar Chart

### 5. Dashboard
Developed a Sales Performance Dashboard containing:
- Total Sales
- Category-wise Sales
- Yearly Sales Trends
- Segment-wise Sales
